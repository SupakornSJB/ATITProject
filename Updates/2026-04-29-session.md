## Input Pipeline Debugging

**Symptom:** Unity received gRPC events (`[IoTGameServiceImpl] InputBatch — 1 events`) but nothing happened in-game.

**Root cause:** `GameInputRouter` was not in the scene as a spawned NetworkSingleton. `InputEventDispatcher.OnReceived` had only 1 subscriber (`IoTInputManager.BroadcastInputToClients`) — `GameInputRouter.HandleInput` was never subscribed.

**Diagnostic added:** `[InputEventDispatcher] Drain — player=... input=... subscribers=N` log inside `Drain()`. Confirmed subscribers=1.

**Fix:** `GameInputRouter` must be added to `SampleScene` as a GameObject with a `NetworkObject` component.

**Phase guard removal:** Input routing was previously gated on `SessionPhase.Active`. Changed to always route (ready-up and gameplay simultaneously). Later reverted to phase guard in Phase 5.

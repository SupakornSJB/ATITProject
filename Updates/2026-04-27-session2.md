# Session Log — 2026-04-27 (2)

## Phase 3.3
No Unity changes. gRPC keep-alive handled by ASP.NET Kestrel automatically.

## Phase 4 — Library Foundation + Dispatcher Refactor

### New library files (`Assets/IoTGame/`)
- **`Models/IoTInputEvent.cs`** — record for game input events (PlayerId, DeviceId, InputName, InputType, EventType, Value, Timestamp, SequenceNumber, Auxiliary)
- **`Models/EnvironmentEvent.cs`** — record for environment sensor events
- **`Models/AdminCommand.cs`** — record for admin commands (Command, IssuedBy, Timestamp, Auxiliary)
- **`Core/IoTGameServer.cs`** — init/shutdown facade; holds SharedSecret; no events (developers subscribe to dispatchers directly)
- **`Core/InputEventDispatcher.cs`** — drains InputQueue each frame, fires `static OnReceived(IoTInputEvent)`
- **`Core/EnvironmentEventDispatcher.cs`** — drains EnvironmentQueue each frame, fires `static OnReceived(EnvironmentEvent)`
- **`Core/AdminCommandDispatcher.cs`** — drains AdminCommandQueue each frame, fires `static OnReceived(AdminCommand)`
- **`Abstractions/IoTGamePlayerController.cs`** — abstract NetworkBehaviour base for player objects
- **`Abstractions/IoTGameEnvironmentController.cs`** — abstract NetworkBehaviour base for environment controller

### New developer files (`Assets/Scripts/Managers/`)
- **`GameInputRouter.cs`** — subscribes to `InputEventDispatcher.OnReceived`; owns all ready-up and gameplay routing (ship/bird/stage); extracted from IoTInputManager

### Renamed
- **`GameRoundManager` → `GameSessionManager`** — "round" was a misnomer; this manages one complete game session
- **`RoundPhase` → `SessionPhase`** — enum values unchanged (Waiting/Countdown/Active/Ended)
- **`RoundTimer` → `SessionTimer`** — NetworkVariable rename

### Modified
- **`IoTInputManager`** — now pure library orchestrator: calls the 3 dispatchers' Drain() each Update(), broadcasts inputs to clients via ClientRpc for debug display; all routing logic removed
- **`IoTGameServiceImpl`** — added shared secret validation (`x-iotgame-secret` header); queues now use new record types; `EnvironmentEvent` struct replaced by `IoTGame.Models.EnvironmentEvent`
- **`ServerBootstrap`** — calls `IoTGameServer.Initialize/Shutdown`; parses `-sharedSecret` CLI arg; client sends `spectator:preferredPlayerId` payload
- **`ConnectionApprovalHandler`** — all clients approved as spectators unconditionally; tracks preferredPlayerId per clientId; spawning no longer triggered on connect
- **`GameSessionManager`** (was GameRoundManager) — subscribes to `AdminCommandDispatcher.OnReceived`; handles `session_start` with auxiliary params; no more direct queue drain
- **`EnvironmentController`** — subscribes to `EnvironmentEventDispatcher.OnReceived`; no more direct queue drain

### Cascade rename (no logic changes)
`RoundUIManager`, `PlayerShip`, `BossEnemyBird`, `EnemySpawnManager`, `BirdSpawnManager`, `PipeSpawnManager` — all `GameRoundManager`/`RoundPhase`/`RoundTimer` references updated

### Architecture summary
```
[gRPC thread]
  IoTGameServiceImpl → InputQueue / EnvironmentQueue / AdminCommandQueue

[Unity main thread — IoTInputManager.Update()]
  InputEventDispatcher.Drain()       → OnReceived → GameInputRouter
  EnvironmentEventDispatcher.Drain() → OnReceived → EnvironmentController
  AdminCommandDispatcher.Drain()     → OnReceived → GameSessionManager
```
